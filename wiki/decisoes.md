# Registro de decisões

Decisões são escolhas sobre o que fazer ou recomendar: caminho de análise, método, escopo, base de dados de referência, recomendação ao cliente, abandono de uma alternativa. As conclusões (o que entendemos) ficam nas análises; aqui fica o que foi escolhido a partir delas.

- Cada decisão diz **quem concordou**. Se não estiver claro, o registro diz isso e abre uma pendência.
- Decisões não são apagadas. Quando mudam, recebem o status "Substituída por D-xxx" ou "Revogada", com o motivo.
- As mais recentes ficam no fim. Formato: [modelos/decisao.md](../modelos/decisao.md).
